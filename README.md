Sou cientista da computação e engenheiro front-end, trabalhando com a web desde 2012. Ajudo times de produto a transformar problemas complexos em aplicações performáticas, escaláveis e fáceis de manter — com responsabilidades bem separadas, contratos estáveis e código que a próxima pessoa consiga entender.
I'm a computer scientist and front-end engineer working on the web since 2012. I help product teams build fast, scalable, and maintainable applications through clear boundaries, stable contracts, and pragmatic architecture.

Criei o **[Jails.js](https://github.com/jails-org/Jails)**, um framework minimalista para micro-frontends baseado em Web Components, SSR e arquitetura MVC. Também escrevo sobre arquitetura web, composição de ilhas e as escolhas de engenharia por trás de software durável.
I'm the creator of **[Jails.js](https://github.com/jails-org/Jails)**, a minimalist micro-front-end framework built on Web Components, SSR, and MVC. I also write about web architecture and the engineering decisions behind durable software.

> Minha ideia favorita de boa arquitetura: fazer o problema parecer menor do que parecia.
> Good architecture makes the problem feel smaller than it first appeared.
